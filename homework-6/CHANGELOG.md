# Changelog — АРМ оператора ИС «Умный кампус»

Все значимые изменения клиентского модуля «АРМ оператора» и утилиты обновления Campus.Arm.Updater.

Формат основан на [Keep a Changelog 1.1.0](https://keepachangelog.com/ru/1.1.0/),
версии соответствуют [Semantic Versioning 2.0.0](https://semver.org/lang/ru/).

## [Unreleased]

### Fixed
- Миграция `003_add_reader_zone.sql`: исправлено имя колонки `reader_zone` (в 2.5.1 была создана `readr_zone`).

## [2.6.0] - 2026-10-24 [YANKED]

Пакет отозван: на сервер обновлений выложен архив, контрольная сумма которого не совпадает с манифестом.
Ни на одном АРМ не установлен — утилита отклонила пакет до начала установки.

## [2.5.1] - 2026-10-23 [YANKED]

Отозван после опытной эксплуатации в кольце canary: на АРМ ARM-KPP-01 не пройдена проверка
«Локальная БД SQLite», выполнен автоматический откат на 2.5.0.

### Added
- Зона прохода для считывателя (колонка `access_events.reader_zone`).

## [2.5.0] - 2026-10-22

### Added
- Учёт идентификатора считывателя в журнале проходов: колонка `access_events.reader_id`
  (миграция `002_add_reader_id.sql`, схема БД v2).
- Утилита **Campus.Arm.Updater 1.0** (C#, .NET 8): команды `check`, `update`, `healthcheck`,
  `rollback`, `status`, стенд опытной эксплуатации `demo-init`.
- Развёртывание по кольцам Canary / Stable и установка по схеме Blue-Green (слоты `blue` / `green`).
- Резервное копирование `appsettings.json`, кэша справочников и локальной БД SQLite перед каждым
  обновлением с проверкой SHA-256 и ротацией копий.
- Цепочка Health Check после обновления: целостность установки и данных → локальная БД → центральный API
  (`https://api.ipify.org?format=json`) → считыватель карт; задержка каждой проверки пишется в журнал.
- Акт готовности АРМ к промышленной эксплуатации (`reports/ACT_<АРМ>_<дата>.md`).
- Автоматический откат при провале критичной проверки и команда ручного отката с переустановкой
  предыдущей версии с сервера обновлений.
- Эксплуатационная документация: [OPERATOR_MANUAL.md](OPERATOR_MANUAL.md), [UPDATE_GUIDE.md](UPDATE_GUIDE.md).

### Changed
- Пакеты обновлений проверяются по SHA-256 из манифеста до любых изменений на АРМ.
- Внешний IP-адрес АРМ в журналах и актах маскируется (`95.24.*.*`).

### Fixed
- Таймаут обращения к API больше не «подвешивает» проверку: каждая попытка ограничена
  `ApiTimeoutSeconds`, выполняется до 3 попыток с паузами 0,5 → 1 → 2 с.
- Ошибки ввода-вывода при загрузке пакета и копировании файлов (файл занят, сетевая папка недоступна)
  обрабатываются повтором, а не аварийным завершением.

### Breaking Changes
- Нет. Схема БД v2 обратно совместима с клиентом 2.4.0 (колонка `reader_id` допускает NULL).

## [2.4.0] - 2026-10-21

### Added
- Базовая версия АРМ оператора КПП: регистрация проходов по картам, пропуск гостей, журнал проходов,
  автономный режим с очередью синхронизации.
