# АРМ оператора КПП ИС «Умный кампус». Руководство оператора

Документ составлен по структуре ГОСТ 19.505-79 «Руководство оператора».
Версия программы: **2.5.0**. Дата редакции: 24.10.2026.

## Аннотация

Документ описывает работу оператора контрольно-пропускного пункта (КПП) с клиентским модулем
«АРМ оператора» ИС «Умный кампус»: вход в программу, регистрация проходов по картам студентов
и сотрудников, пропуск гостей, работу с журналом проходов, а также действия при сбоях
оборудования, сети и после обновления программы.

## 1. Назначение программы

АРМ оператора КПП предназначено для:

- регистрации проходов через турникет по бесконтактной карте (студенческий билет, пропуск сотрудника);
- ручного пропуска гостей и посетителей с указанием основания;
- просмотра журнала проходов за смену и поиска по номеру карты;
- работы при временном отсутствии связи с центральным сервером (автономный режим):
  события сохраняются в локальной БД и передаются на сервер после восстановления связи.

## 2. Условия выполнения программы

| Требование | Значение |
|---|---|
| Компьютер | АРМ КПП с ОС Windows 10/11 (64 бит), монитор не менее 1366×768 |
| Периферия | считыватель бесконтактных карт (USB/COM), турникет с контроллером |
| Сеть | подключение к сети кампуса; доступ к центральному API ИС «Умный кампус» |
| Программное обеспечение | клиент «АРМ оператора» 2.5.0, среда .NET 8, утилита проверки Campus.Arm.Updater |
| Учётная запись | личная учётная запись оператора (выдаёт администратор АРМ) |

Перед началом смены индикатор состояния в правом нижнем углу окна должен быть **зелёным**
(«Сервер доступен, считыватель готов»).

## 3. Выполнение программы

### 3.1. Запуск и вход

1. Включите АРМ и дождитесь загрузки Windows.
2. Запустите ярлык **«АРМ оператора КПП»** на рабочем столе.
3. Введите логин и пароль оператора, нажмите **«Войти»**.
4. Проверьте в заголовке окна номер АРМ (например, `ARM-KPP-01`), ФИО оператора и версию программы.
5. Нажмите **«Начать смену»** — программа выполнит самопроверку (БД, связь с сервером, считыватель).

> Не передавайте свою учётную запись другим сотрудникам. При смене оператора нажмите
> **«Завершить смену»** и выполните вход под своей учётной записью.

### 3.2. Регистрация прохода по карте

1. Человек прикладывает карту к считывателю.
2. На экране отображаются фото, ФИО, группа/подразделение и результат проверки доступа.
3. Зелёная рамка — проход разрешён, турникет открывается автоматически.
4. Красная рамка — проход запрещён (карта заблокирована, нет доступа в это время). Сообщите причину
   и при необходимости вызовите дежурного администратора.

### 3.3. Пропуск гостя

1. Нажмите **«Гость»**, введите ФИО, документ и цель визита, выберите сопровождающего.
2. Нажмите **«Пропустить»** — турникет откроется один раз, событие запишется в журнал с отметкой «гость».

### 3.4. Журнал проходов

1. Вкладка **«Журнал»** показывает события текущей смены.
2. Поиск — по последним 4 символам номера карты или по ФИО.
3. Кнопка **«Выгрузить»** сохраняет журнал смены в файл для передачи руководителю.

### 3.5. Завершение работы

1. Нажмите **«Завершить смену»** — программа отправит несинхронизированные события на сервер.
2. Дождитесь сообщения «Синхронизация завершена» и закройте программу.
3. Не выключайте АРМ во время установки обновлений (на экране сообщение «Идёт обновление»).

## 4. Сообщения оператору

| Сообщение | Причина | Действия оператора |
|---|---|---|
| «Проход разрешён» | карта действительна | действий не требуется |
| «Доступ запрещён» | карта заблокирована или нет прав в это время | сообщить причину, при споре — вызвать администратора |
| «Карта не распознана» | карта повреждена или неверно приложена | приложить карту повторно; при повторе — пропуск через «Гость» |
| «Считыватель не отвечает» | отключён кабель, сбой считывателя | проверить кабель, см. раздел 5.1 |
| «Автономный режим: нет связи с сервером» | недоступна сеть или центральный API | продолжать работу, см. раздел 5.2 |
| «Идёт обновление, не выключайте компьютер» | плановое обновление АРМ | дождаться завершения (обычно до 2 минут) |
| «Версия возвращена к предыдущей» | обновление не прошло проверку и было отменено | продолжать работу, сообщить администратору |

## 5. Действия при сбоях

### 5.1. Сбой считывателя карт

1. Проверьте, что кабель считывателя подключён и индикатор считывателя светится.
2. Нажмите **«Сервис → Проверить считыватель»**.
3. Если считыватель не восстановился — пропускайте людей через **«Гость»** с отметкой «сбой считывателя»
   и сообщите администратору АРМ (телефон в карточке на рабочем месте).

### 5.2. Нет связи с сервером (автономный режим)

1. Индикатор состояния становится **жёлтым**, работа продолжается.
2. Проходы записываются в локальную БД и очередь синхронизации; ничего удалять и перезапускать не нужно.
3. Если автономный режим длится более 30 минут — сообщите администратору.

### 5.3. Сбой после обновления программы

1. Если после обновления программа не запускается, выдаёт ошибки или не видит считыватель —
   **не переустанавливайте программу самостоятельно**.
2. Сообщите администратору АРМ: номер АРМ, время, текст сообщения.
3. Администратор выполняет проверку готовности и при необходимости откат на предыдущую версию
   (см. [UPDATE_GUIDE.md](UPDATE_GUIDE.md), раздел 6). Перед ручным откатом администратор
   завершает синхронизацию событий с сервером, поэтому проходы за смену не теряются.

### 5.4. Аварийное отключение питания

После включения АРМ запустите программу и выполните вход. Программа проверит целостность локальной БД;
события, записанные до отключения, будут переданы на сервер автоматически.
